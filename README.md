# 轻量级桌面防久坐与饮水提醒工具 (Break & Hydration Reminder)

> **设计哲学**：**“强视觉提醒，零操作阻断”** —— 专为长时间高强度使用电脑的学习者、程序员与文字工作者打造。全屏半透明蒙版打断视觉疲劳，督促起身饮水活动；鼠标操作完全穿透，绝不打断紧急工作与灵感。

---

## 🌟 核心特色与技术亮点

* **🖱 鼠标完全穿透 (Click-Through)**：
  * 基于 Windows 原生扩展窗口样式 (`WS_EX_LAYERED | WS_EX_TRANSPARENT | WS_EX_NOACTIVATE`)。
  * 蒙版在视觉上全屏覆盖，但所有鼠标点击、拖拽、滚轮完全穿透到底层软件；弹窗时绝不抢走输入焦点，写代码/交作业打字不中断。
* **🎨 双层协同解绑透明度**：
  * 背景暗色幕布（或全屏壁纸）与前景倒计时文字解耦。
  * 即使把背景调到极淡（如 15%），倒计时大字与关怀语录依然纯正清晰不发虚。
* **🖼 全屏壁纸等比例居中填充 (Cover/Fill)**：
  * 采用 Pillow `ImageOps.fit` 算法，严格锁定图片原生宽高比，任意比例壁纸铺满全屏绝不变形拉伸。
* **🔤 400+ 系统字体枚举与自主 TTF/OTF 导入**：
  * 自动检索 Windows 系统安装的全部字体，中英文自由切换；
  * 提供“自主导入字体”功能，通过 Windows GDI 底层私有加载接口，无需管理员权限安装即可使用任意个性化本地字体。
* **👁 实时效果无损预览**：
  * 在偏好设置面板中可一键预览当前草稿样式，按 `ESC` 或 8 秒后自动退出，绝不重置正在进行的 45 分钟工作计时。
* **🧠 智能防打扰感知**：
  * **离开电脑自动重置**：调用 Windows 内核 `GetLastInputInfo` 检测全局键鼠空闲，离开电脑超过阈值（如 5 分钟）自动归满工作计时；
  * **全屏应用智能避让**：前台全屏看课、放映 PPT 或玩游戏时智能顺延蒙版。
* **⚡ 极致轻量与低资源消耗**：
  * 静默运行内存仅约 **15 MB**，后台 CPU 占用恒定 **0.0%**。

## 🚀 快速上手 (Quick Start)

### 方式一：一键自动配置（最推荐，小白友好）
1. 将本项目下载或克隆到你的 Windows 电脑上；
2. 鼠标双击运行根目录下的 **`一键安装与配置(初次使用请双击).bat`**；
3. 脚本会自动为你安装所需依赖库，并自动在你的 Windows 桌面上生成带有专属小水滴图标的 **`防久坐与饮水提醒`** 快捷方式；
4. 以后直接双击桌面图标即可在后台完全静默运行！

### 方式二：手动安装与启动
如果你习惯使用命令行：
```powershell
# 1. 安装核心依赖
pip install -r requirements.txt

# 2. 生成桌面快捷方式
python create_desktop_shortcut.py

# 3. 静默启动程序（无黑框控制台）
pythonw main.pyw
```

## ⚙ 常用交互与快捷键

| 操作 | 交互方式 / 快捷键 | 说明 |
| :--- | :--- | :--- |
| **紧急跳过休息** | **`Ctrl + Shift + Space`**（默认，可在设置中修改） | 休息蒙版期间遇紧急情况，按下立即关闭蒙版并重置工作计时 |
| **退出预览** | **`ESC`** 或 **`Ctrl + Shift + Space`** | 在设置面板预览样式时，按下立即返回设置窗口 |
| **查看剩余时间** | 鼠标悬停右下角系统托盘图标 | 浮动气泡动态显示 `距离下次休息还有 XX:XX` |
| **打开设置面板** | 右键托盘图标 ➔ 选择 **`⚙ 偏好设置...`** | 自由调节时长、透明度、字体、加粗、壁纸、开机自启等 |
| **立即进入休息** | 右键托盘图标 ➔ 选择 **`☕ 立即进入休息`** | 手动强制触发一轮休息 |
| **彻底退出软件** | 右键托盘图标 ➔ 选择 **`❌ 彻底退出`** | 安全注销全局快捷键与托盘常驻 |

## 📂 项目模块架构

项目采用现代桌面客户端标准的分层解耦架构：

```text
├── main.pyw                        # GUI 无黑框静默启动入口
├── main.py                         # 应用程序总控制器
├── config.json                     # 本地持久化配置（热重载与防呆回退）
├── requirements.txt                # Python 依赖清单
├── 一键安装与配置.bat               # Windows 一键环境部署与桌面图标生成
├── 一键启动(无黑框静默).bat         # 双击直接启动
├── create_desktop_shortcut.py      # 利用 WScript.Shell 动态创建桌面 .lnk 快捷方式
│
├── core/                           # 【核心业务层】（纯逻辑，无 UI 依赖）
│   ├── config_manager.py           # 配置管理器（观察者模式广播变动）
│   └── state_machine.py            # 四态有限状态机 (WORKING / PRE_BREAK / BREAKING / PAUSED)
│
├── os_layer/                       # 【操作系统适配层】（纯 Windows Win32 API 封装）
│   ├── win_api.py                  # 高 DPI 感知、多显示器虚拟桌面、鼠标穿透样式注入
│   ├── font_manager.py             # 系统全部字体枚举与外部 TTF/OTF 私有无权限加载
│   ├── autostart.py                # Windows 注册表当前用户开机自启管理
│   ├── idle_detector.py            # 基于 GetLastInputInfo 的用户闲置感知
│   ├── session_listener.py         # 独占全屏应用程序避让检测
│   └── hotkey_manager.py           # 全局快捷键注册与监听
│
└── ui/                             # 【用户界面层】
    ├── overlay_window.py           # 双层协同全屏穿透休息蒙版（背景与文字解耦）
    ├── toast_window.py             # 休息前 30 秒右下角无焦点预告卡片
    ├── settings_dialog.py          # 现代化分页偏好设置面板（底部按钮永不遮挡）
    └── tray_icon.py                # 系统托盘图标、悬停气泡与上下文菜单
```
